# 证据与数据结构

## 样本台账

每个有效样本至少记录：

| 字段 | 要求 |
| --- | --- |
| sample_id | 稳定唯一编号，建议“地区-机制缩写-序号” |
| region / country | 地区与可能国家；不确定时标注 |
| language | 帖文和检索语言 |
| source_type | 用户自发、商业合作、官方内容、付费广告、竞品模板 |
| account_type | 普通用户、创作者、达人、品牌、App 官方 |
| platform / account | 平台与账号或广告主 |
| published_or_active_at | 发布日期或广告活跃区间 |
| captured_at | 采集时间和时区 |
| direct_url_or_path | 原帖直链；无法分享时写准确入口路径 |
| screenshot | 能看清最终效果的截图或素材引用 |
| visible_metrics | 点赞、评论、收藏、分享、播放或广告状态；不可见则明确写出 |
| mechanism | 可复现的内容、模板或视觉机制 |
| format | 画布比例、图片数量、分格、裁切、层级和资源形态 |
| visual_keywords | 3-6 个具体关键词 |
| scene | 使用场景 |
| risk | IP、商标、肖像、字体或不可复用素材风险 |
| discovery_path | 初始入口 -> 扩展线索 -> 最终样本 |

可增加原始标题、文案、话题、音频、广告落地页、产品版本和备注，但不要用附加字段替代最低字段。

## 有效样本门槛

样本必须同时满足：

- 最终效果清晰可辨。
- 来源能被复核，至少有直链或准确入口路径。
- 能确定大致时间范围。
- 与研究主题直接相关，而非只在文案中提及关键词。
- 能提炼出可复用机制或为趋势强度提供证据。

搜索结果缩略图、首页、Logo、二次搬运且找不到来源的图片、看不清机制的封面不计入有效样本。

## 去重规则

- 相同结构只换照片、颜色、贴纸或文案，保留 1-3 个最强代表。
- 同一品牌同一模板保留一个最佳效果和最多一个不同场景变体。
- 同属一个宽泛风格但结构不同，例如撕纸、照片条、杂志跨页，应分别保留。
- 转发和搬运不计作独立复现；同一创作者多帖仍只算一个独立账号。

## 趋势卡

| 字段 | 内容 |
| --- | --- |
| trend_name | 统一、可理解的名称 |
| mechanism | 可制作的结构描述 |
| first_seen | 首次发现的时间、平台和地区 |
| main_regions | 核心地区与扩散路径 |
| scenes | 主要使用场景 |
| origin_pattern | 用户自发、产品/广告推动或混合 |
| lifecycle | 新生、加速、稳定、衰退、常青、待验证 |
| evidence_counts | 30/90/180 天样本、独立账号、平台、地区、商业证据 |
| score | 0-12 分与逐项理由 |
| reusable_modules | 可产品化的最小模块 |
| risks | 版权、样本偏差和可访问性限制 |
