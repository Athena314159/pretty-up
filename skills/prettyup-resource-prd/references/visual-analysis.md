# 视觉参考分析

仅在任务包含图片、视频帧、竞品截图或多份样片时读取。

## 素材账本

内部使用以下字段，不必默认完整展示给用户：

| 字段 | 说明 |
|---|---|
| 编号 | 使用用户图号或稳定文件名 |
| 可观察内容 | 人物、部位、色彩、材质、构图、文字 |
| 参考角色 | 目标效果 / 风格语气 / 展示版式 / Before / After / 反例 |
| 资源归属 | 属于哪一个贴纸、色号或配方 |
| 关系 | 同资源多视角 / 同人物前后 / 跨人物适配 / 重复 / 未知 |
| 确定性 | 用户明确 / 视觉强证据 / 暂定 / 待确认 |

## 证据优先级

1. 用户明确说明。
2. 同一人物、背景、裁切和结构等稳定视觉证据。
3. 文件顺序或命名线索。
4. 常见行业习惯。

低级证据不得覆盖高级证据。不能只因图片相邻就断言是 Before/After，也不能因不同人物效果不同就断言是多套配方。

## 视觉拆解顺序

1. 先看资源识别点：第一眼看到什么。
2. 再看空间分布：效果在哪里、范围多大、中心和边缘如何变化。
3. 再看材质：哑光、水光、珠光、金属、颗粒、透明或柔焦。
4. 再看结构关系：是否遵循唇纹、五官、脸型、表情和透视。
5. 再看尺度表现：正常视角、近景、缩略图分别保留什么。
6. 最后看适配：肤色、脸型、光照、角度和场景变化后，什么不变、什么调整。

## 静态图边界

静态图只能支持静态视觉判断。除非用户或素材明确提供，不要断言偏光随角度变化、贴纸跟随稳定性、动画节奏或实时算法行为。可以将其写为“期望表现”并要求测试，而不是写成已知事实。
