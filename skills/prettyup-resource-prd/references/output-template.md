# 输出模板

根据任务复杂度选用，不要机械输出空栏目。

## 精简派单版

```markdown
## Pretty Up「资源名称」制作需求

**资源身份：** 一句话说明人群/场景、视觉机制和感受。

### 核心效果
- 3至6条最重要、可制作的要求。

### 适配与边界
- 固定项：
- 自适应项：
- 禁止项：

### 交付
- 实际需要的文件、切件、对比图或参数记录。

### 验收
- 正常视角：
- 近景：
- 缩略图：
- 跨人物/肤色/场景：
```

## 复杂配方附录

```markdown
### 素材关系
| 素材 | 角色 | 归属 | 关系 | 确定性 |

### 模块规格
| 模块 | 效果目标 | 固定项 | 自适应项 | 禁止项 |

### Before/After
- 必须来自同一原图。
- 人物位置、裁切、背景和基础曝光一致。
- Before 不刻意做丑，After 不过度失真。

### 待确认项
- 只列会影响资源数量、核心机制或交付范围的问题。
```

## 命名输出

```markdown
**首选：中文名｜English**

选择理由：核心效果对应、目标人群/平台适配、英文真实语义。

备选：
- 长期产品向：
- 社媒趋势向：
- 更强效果表达向：

风险提示：仅列真实存在的歧义或文化联想。
```
