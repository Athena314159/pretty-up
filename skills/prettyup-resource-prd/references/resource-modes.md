# 资源模式

只读取与当前任务对应的章节。

## 面部贴纸与装饰

需要定义：

- 每款核心造型、颜色、材质和彼此差异。
- 面部锚点、左右关系、尺度、旋转和安全区域。
- 表情、转头、遮挡、边缘变形和肤色背景下的可读性。
- 多款资源是同一主题套装还是独立单品。
- 缩略图或宣传图中最应被识别的元素。

短文案优先从四种任务中选择一个：

- 情绪投射：让用户想象“今晚成为谁”。
- 痛点解决：不用会画妆，也能快速完成造型。
- 选择互动：多款中选哪一款。
- 效果承诺：贴上即可完成妆容或出片。

不要同时承担四个任务。默认输出一句首选、2至4句备选和简短选择理由。

## 局部妆效

按需定义：

- 底色：色相、冷暖、饱和度、遮盖力和透肤感。
- 边界：清晰、柔化、晕染、描边或无描边。
- 材质：哑光、缎光、水光、玻璃、珠光或金属。
- 颗粒：大小、密度、颜色、中心与边缘分布。
- 光影：高光和暗部的位置、方向、强弱与结构贴合。
- 解剖：是否保留唇纹、唇峰、下唇体积、眼型或眉毛毛流。
- 组合：唇线与口红、眼线与睫毛等模块如何过渡。
- 适配：浅肤色不发白，深肤色不发灰；不机械套用同一浅色值。

先判断是否使用唇线、描边或外扩。用户后续修改这一点时，应重写丰唇或轮廓机制，而不是只删掉“唇线”三个字。

## 一键美化与美容配方

先确认是“一套配方跨人物测试”还是“多套妆容”。若是一套配方：

- 用一个统一效果身份描述所有样片。
- 区分固定默认参数与算法/人工自适应项。
- 不因为不同人物呈现差异就给每组另起妆容名。
- 参数表中的固定数值必须由用户或真实配置提供；没有数据时仅给参数维度和建议方向。

按需覆盖：肤色、肤质、眉毛、眼影、眼线、睫毛、卧蚕、腮红、鼻部、修容、唇妆、点缀、脸部重塑。

配方必须说明：

- 核心记忆点及模块优先级。
- 人物辨识度和原始肤色的保护规则。
- 不同肤色、脸型、五官量感和拍摄场景的适配逻辑。
- 同一原图的 Before/After 展示约束。
- 套装缩略图、功能切件、参数表和对比图等实际交付物。
- Before 不刻意做丑，After 不靠失真制造差异。
