# 包袋外观课程
当前用户重点：版型(可见轮廓/比例/量感)、材质、配色、时尚感、风格。不能滑向裁片/工程；未展示内部不猜测。
任务链：审美关键词 → 候选品牌 → 代表图初筛 → 两个可比时间段核验 → 两品牌组合 → 约100素材 → 四风格×五款的设计依据。
8—12候选、4—6代表图是探索建议，不是老师要求。原始课题要求以用户提供材料为准，不能把本配置数量套到其他课程。
近期社媒与历史两线并行。最近帖子不等于新款；官网在售不等于当年发布。材质只靠图片写视觉类似/未核实。每条记录轮廓、比例、纹理/光泽、主辅色关系、风格依据、可借鉴方法、任务用途。
独立款式为主要计数单位；同款角度归并。近两年变化可得延续结论，不强造变化。不能用高点赞替代外观研究价值。四风格是个人转化方向，不等于四品牌。
