# 时间与热度排序
1. 符合任务与时间要求才入候选。必需历史材料独立保障覆盖。
2. P1 上升、P2 持续高热、P3 新生待验证、P4 历史、P5 常青。
3. P1 必须有同口径可比时间证据，给出指标、分母、时段及来源。不是当前点赞多就P1。

发布日期、产品/事件日期、页面更新日期、采集时间分别记录。搜索引擎显示日期不直接作为原帖发布时间。相对日期按采集时间及时区解释，精度不够就保留范围。

同帖多快照：速度=指标增量/间隔天数。至少三个可比快照才比较前后速度得到加速度。减少的数值先检查删赞、平台校正和口径变化，不直接当负增长。
同查询分时段：比较等长时段下发布量、独立账号及互动分布；记录检索覆盖差异，不把采样变大解释为真实增长。
相对增幅同时展示绝对增量、基数、持续性；基数为0不计算百分比。异常营销、搬运和同主体分开标注。
平台内部在可比样本中排序，跨平台展示各自排名/分档及独立扩散证据。没有共同口径不声称全网排名。
旧内容在最近三个月重新增长可P1；最新内容尚未热可P3。高热常青与上升不是同一标签。
结论固定展示：增长依据、当前热度、可信度、时间覆盖、局限。没有增长数据写待验证，不能用综合分替代增长证据。
