# 任务与模式
任务卡记录 task_id、问题、目标、交付、重点、排除、数量及计数单位、时间、地区、语言、用户要求、材料要求、建议、待确定项。
缺少非关键输入时说明假设继续；来源中旧要求不得覆盖用户最新纠偏。

工作模式：最新产品、内容和需求信号 + 历史竞品、案例生命周期。输出证据支持的建议、适用条件及风险。
学习模式：最新作品、研究和表达 + 历史演变、经典方法、对照案例。输出作业对应关系、引用、可借鉴方法；预测不能冒充事实，设计设定不能冒充用户调查。
两模式都必需覆盖近期和历史两线，简单问题可短述背景，明确只查某一范围时遵循用户范围。

分轮检索：发现(多入口内容样本) → 归类(实际内容/视觉结构) → 扩展(作者与内容关系) → 验证(日期/增长/独立来源) → 补缺。工作模式开放社媒研究采用work-discovery.md；具体词不是候选收录门槛。先找适用来源，再按覆盖空白扩展语言与平台。
