# 来源选择
先发现当前可用的连接器/工具，再使用网页搜索；需要站内搜索时使用授权浏览器且核对真实UI功能。每平台单独记录日期筛选、排序、读取原帖、登录状态与最后验证时间，不预设全平台支持最新排序。
社媒：发现新表达、独立复现、穿搭及用户问题。官网/系列发布：核对身份、材质、产品和年份。专业媒体/买手店：发现与补充。文献/官方文档：理论和事实核验。
平台清单按问题选，不穷举；搜索中从真实原帖、评论、作品集、标签、品牌名发现新入口，记录新增词的来源和有效命中。
工作模式开放社媒研究按work-discovery.md组合宽场景、作者作品流、内容关系与可用视觉检索；搜索引擎索引不是社媒总体。记录每种入口实际可读媒体数量和不可达部分，不能用工具博客代替用户原帖覆盖。
公开搜索可用site与时间筛选辅助发现，必须打开原始结果验证。失败记录原因、断点和替代路径。不能绕过访问控制。
网页UI提供的外部搜索链接只是检索入口；点击不等于已读取结果。若只有摘要，记录verification=lead。
