# 视觉资源工作
覆盖PrettyUp美妆/模特/活动资源及拼图拼贴，按本次业务选择维度。近期上升与历史热点都检索；用户、品牌、广告、竞品上新分开统计。
拼图关注比例、图片数、遮罩、层级、信息位、配色、素材形态；美妆关注可见妆容元素、配色、模特需求和场景。风格名称必须落到可生产视觉规则。
从样本提取当地语言、标签、模板名、App水印和原作者扩词；样本量与地区配额由任务决定。
按../work-discovery.md先广泛发现，再看图归类；无标签、仅日常文案和暂不能命名的视觉表达也可入候选。扩词用于补缺，不能用预设风格词决定哪些作品有资格被看见。
交付每条方向的来源、表现方法、可转化模块、适用场景与IP/肖像/字体等素材限制。业务价值高不自动等于热度上升。

## 用户实际使用场景（用户要求真实生活/自拍案例时）
按“个人生活分享语境 → 本人或亲友照片采用依据 → 目标拼图形式 → 完整原帖核验 → 去重与时间热度”筛选。作品发在社媒上不自动等于用户生活分享。模板作者、转载灵感账号、实际使用者分别记录；作者自拍归属不明时保留待核验。
简约排版可以符合需求，不能把排除基础双拼扩大为排除全部简约设计。基础网格、艺术拼贴等只在本任务明确排除时筛掉，不能成为其他任务的通用禁令。
