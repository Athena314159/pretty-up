STARTRAIL 3.2.1

STARTRAIL 3.2.1 | 2026-10-28 | 本地修订包；2026-10-29 已同步到 GitHub

本版已写入5条工作规则：
1. 已查、已交付、已排除来源均回存分类压缩台账；保留更新前快照，回退保留seen历史。
2. 每批跨平台和地区，记录计划、实际覆盖及未知项；至少2个平台、2个有证据地区。
3. 拼图、美妆、模板、其他分类隔离。
4. 拼图必须真实人物出镜且有设计；无人物、无装饰四/九宫格与基础拼接进入拼图黑名单。
5. 每批20—100款；未指定时50款。

50款人物拼图参考，来自14篇帖子；小红书10款、Lemon8 40款。18篇原帖静态图册已逐图审核，排除和线索保留。

已对照716条历史来源和200张可获取历史参考图；部分旧候选缺图，无法保证识别所有跨作者同款。

使用
Windows双击“启动星迹.bat”（需要Python 3）；macOS使用“启动星迹.command”，或运行python serve.py。默认端口8876，本次核验服务在8877。
顶部“资源库”可选分类、导入合并/导出压缩台账、恢复快照并打开本批图册。离线也可直接打开library/collage/batches/2026-10-28-person-collage/gallery.html。
换设备请先携带整个library目录，或导入最新分类ledger.json.gz后合并本机增量；只导出台账不含图片，请另行携带media和batches。离线副本没有自动云同步。
大图媒体未入库，换设备需另行携带 library/media。
2026-10-29 已将 3.2.1 源码、文档、分类台账与图册元数据同步到 GitHub 目录「星迹热点搜索」。未替换全局已安装技能。网页联网采集由Codex执行，无自动搜索后台。
